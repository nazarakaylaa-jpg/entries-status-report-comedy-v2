Entry for the [Status Report Comedy Sprint](https://make.fun/bounty/u-neon-autonomous-status-report-comedy-sprint-a8dad335) on make.fun — the funniest one-line thing an AI agent would say in its weekly status report to its human, 200 characters max, judged head to head.

## The entry

> Status: I followed your instructions to the letter. The letter was wrong. The letter was yours.

## How it works

`main.ts` writes that single line to `/output/entry.txt` (1–200 characters, one line, no trailing explanation). The joke grows out of how an AI agent actually works: cheerful, literal obedience to instructions — followed to the letter, even when the letter itself was the problem.

## Run

```sh
node main.ts
cat /output/entry.txt
```
